## AI CAD Bridge 0.2.0 — beta

Plugin local de Codex para modelar piezas y ensamblajes de Autodesk Inventor en milímetros.

### Descargar e instalar

1. Descarga **ai-cad-bridge-source-0.2.0.zip** de los archivos de esta versión.
2. Extrae el ZIP en una carpeta permanente y ejecuta **INSTALL.cmd**.
3. Abre Inventor, reinicia Codex y selecciona **AI CAD Bridge** en un chat local nuevo.

Requiere Windows x64, Python 3.11–3.14, Codex con plugins e Inventor instalado con licencia. El ZIP `plugin` es para importación manual y requiere haber instalado el runtime; el ZIP `source` incluye el instalador recomendado. `SHA256SUMS.txt` permite verificar ambos archivos.

### Funciones

- Croquis, extrusiones, revoluciones, agujeros, redondeos, chaflanes, patrones y simetría.
- Piezas monolíticas de un sólido/una operación, comprobación de dimensiones y colores por cara.
- Ensamblajes sencillos, modificación mediante copia, exportación STEP/STL y vistas previas.
- Validación de comandos, límites de carpeta, protección contra sobrescritura y reversión de operaciones fallidas.

**Compatibilidad:** Inventor 2022 probado con 21 casos CAD y seis verificaciones de acabado. Inventor 2017–2021 y 2023–2027 son candidatos por API documentada, pendientes de pruebas reales. Las pruebas de GitHub Actions validan el protocolo y el código; sus runners no incluyen Inventor.

Código abierto bajo licencia MIT. No es un producto oficial de Autodesk ni de OpenAI. Las apariencias son visuales; las medidas calculadas por fotografías siguen siendo estimaciones.
