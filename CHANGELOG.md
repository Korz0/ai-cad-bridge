# Changelog

## 0.2.0 — 2026-10-25

- Packaged a local Codex plugin with portable and compatibility manifests, a repository marketplace, modeling skill and four MCP tools.
- Added a per-user PowerShell installer, double-click entrypoint, diagnostics and non-destructive uninstall.
- Replaced the Inventor 2022-only gate and fixed type-library binding with runtime COM type-library detection, a 2017–2027 candidate policy, version guards and requested-feature probes.
- Generalized one-solid/one-feature consolidation, per-face appearances and expected-envelope checks.
- Added protocol/validation tests, live finishing verification, Windows CI, bilingual onboarding, official Autodesk API references and GitHub release packaging.

Only Inventor 2022 has real CAD execution evidence. Other enabled releases are candidates, not certified versions.
